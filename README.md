# React Gallery App - Urban & Environmental Data Stories

A modern, responsive React application showcasing a collection of interactive data stories focused on urban challenges and environmental conservation in Indian cities.

## 🚀 Overview

This project is a curated gallery of "Data Stories" that visualize and describe various urban and environmental issues. It features a clean, premium dark-mode interface with interactive cards and smooth transitions.

### Key Features
- **Interactive Story Gallery**: A responsive grid of cards detailing environmental and urban data insights.
- **Dynamic Tooltips**: Hover over stories to see deep-dive descriptions and impact summaries.
- **Premium UI/UX**: Built with a sleek dark aesthetic, glassmorphism elements, and smooth micro-animations.
- **Responsive Design**: Optimized for all screen sizes from mobile to desktop.

## 🛠️ Tech Stack
- **Frontend**: React 19
- **Bundler**: Vite
- **Routing**: React Router DOM v7
- **Styling**: Vanilla CSS (Modern CSS features, Gradients, Animations)

## 📂 Project Structure
- `src/pages/Gallery.jsx`: The core interactive gallery component.
- `src/pages/Home.jsx`: Minimalist landing page with dynamic visuals.
- `src/App.jsx`: Main application wrapper with layout and routing.

## 🌟 Data Stories Focus
This application highlights critical urban issues such as:
- Urban Deforestation in Bangalore
- Forest Fire Pollution in Pune
- Waste Management in Varanasi
- Predictive Ambulance Logistics
- Urban Heat Island Effects
- Lake Restoration Efforts
